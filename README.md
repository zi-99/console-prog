# Student Management & Results Analysis System

## Project Overview
A JavaScript-based student management system that calculates student averages, assigns letter grades, evaluates academic results, and identifies students eligible for mercy marks.

## Features
- Student management using JavaScript Classes.
- Calculate grades average using reduce().
- Assign letter grades using conditional statements.
- Evaluate student results based on average and attendance.
- Identify struggling students using filter().
- Apply mercy marks using map().
- Calculate new averages using reduce().
- Display organized reports using console.table().

## Technologies
- JavaScript (ES6+)
- Object-Oriented Programming (OOP)
- Array Methods
- Browser Developer Console

## How to Run
1. Download or clone the repository.
2. Open your browser.
3. Open Developer Tools using F12.
4. Navigate to the Console tab.
5. Paste the contents of script.js and press Enter.
